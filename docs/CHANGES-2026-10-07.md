این سند وضعیت پس از اصلاح را شرح می‌دهد. [گزارش بررسی اولیه](REVIEW.md) برای سابقه حفظ شده و نتیجه QA آن به نسخه جدید تعمیم داده نمی‌شود. تغییرها فقط در فرانت‌اند انجام شده‌اند؛ سورس بک‌اند کنار پروژه برای تطبیق قرارداد به‌صورت خواندنی بررسی شده است.

## افزوده‌ها و حذف‌ها

`src/error.tsx` حذف و boundary درست در `src/app/error.tsx` اضافه شده است. helperهای auth و API، اعتبارسنجی upload، صفحه ۴۰۴، robots/sitemap، helper فهرست مدیر، Pagination و تست‌های regression اضافه شده‌اند. import فونت‌های Google و گزینه‌های اجتماعی خارج از قرارداد حذف شده‌اند. صفحه پرداخت، قوانین، مقاله یا کیف پول ساختگی اضافه نشده است؛ لینک‌های امکانات آماده‌نشده غیرفعال شده‌اند.

نام دقیق تمام فایل‌های افزوده، حذف و تغییرکرده در [فهرست تغییر فایل‌ها](CHANGE-FILES.md) و سورس فعلی در [SOURCE-MAP](SOURCE-MAP.md) ثبت می‌شود. نسخه پشتیبان اولیه در `C:/webpro/front-iran-plaza-qa-backup-20261007-103411` است؛ `.env` در آن کپی نشده است.

## سازگاری و موارد وابسته به بک‌اند

سورس محلی `C:/webpro/back-iran-plaza` نام multipart `file`، مسیر نمایش `/api/files/:id`، سقف ۲۰MB، `durationMin`، چهار کلید social و دو مسیر اعلان `/notifications` و `/api/notifications` را تأیید می‌کند. بنابراین مسیر قبلی اعلان و قرارداد فایل از ابتدا الزاماً خطا نبودند. اکنون فرانت برای یکدستی از `/api/notifications` استفاده می‌کند.

در همین سورس محلی، `onboardingStep`، endpoint `onboarding/advance` و پشتیبانی categoryIds در UpdateBusinessDto/ویرایش دیده نمی‌شوند. فرانت به بک‌اند سازگار با بسته onboarding نیاز دارد. جزئیات در [سازگاری بک‌اند](BACKEND-COMPATIBILITY.md) است. سورس محلی را برابر نسخه سرور فرض نمی‌کنیم؛ سرویس پیکربندی‌شده هنگام بررسی HTTP در دسترس نبود.

کوکی قدیمی در ورود یا refresh موفق به scope جدید مهاجرت می‌کند. `SITE_URL` اختیاری و server-only است؛ برای canonical و sitemap production باید دامنه واقعی با HTTPS تنظیم شود. بسته dependency جدیدی اضافه نشده و lockfileها حذف نشده‌اند؛ pnpm مرجع معرفی شده و npm lock فقط metadata engines را منعکس می‌کند.

تست HTTP fixture از TCP واقعی روی loopback استفاده می‌کند، اما بک‌اند آزمایشی است؛ آزمون زیرساخت، SMS، دیتابیس، حساب واقعی یا E2E کامل نیست. تست JWT امضای رمزنگاری واقعی دارد و تست کوکی store را mock می‌کند. سرور موقت production پس از بررسی متوقف شد. هیچ استقرار یا commit انجام نشده است.

Git repository در این پوشه موجود نیست و commit انجام نمی‌شود؛ staged diff و check Git قابل اجرا نیستند. کنترل جایگزین، مقایسه فایل‌ها با پشتیبان اولیه و بررسی محتوا/مسیر/encoding است. بدون بک‌اند زنده و baseline رسمی، QA کامل قرارداد API و migration را موفق اعلام نمی‌کنیم.
