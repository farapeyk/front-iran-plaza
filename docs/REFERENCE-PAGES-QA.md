# اصلاح ظاهر خانه و پروفایل کسب‌وکار — ۲۰۲۶-۱۰-۱۲

مرجع این تسک دو تصویر پیوست کاربر است. اصلاحات در فرانت انجام شده‌اند و قرارداد API، بک‌اند، دیتابیس و صفحات مدیریت تغییر نکرده‌اند.

## تغییرات

- خانه: جای تصویر شهر و جستجو، فاصله‌های بخش‌ها، کارت ثبت‌نام، نمایش نظرات موجود در سورس طراحی و فوتر مطابق مرجع تنظیم شدند.
- پروفایل: کارت معرفی در ستون چپ، محتوای اصلی در ستون راست، کارت‌های سه‌تایی محصولات، فیلتر دسته‌بندی، قیمت تخفیف‌دار، کنترل گالری و ترتیب بخش‌ها اصلاح شدند.
- استایل‌ها به دو صفحه محدودند؛ داده‌های کسب‌وکار از همان سرویس‌های موجود دریافت می‌شوند.

## بررسی‌ها

| فرمان یا بررسی | نتیجه نهایی |
| --- | --- |
| `pnpm run build` | موفق، exit 0؛ روی کپی ایزوله فرانت با سورس نهایی و بدون env خصوصی |
| `pnpm run typecheck` | موفق، exit 0 |
| `pnpm run lint` | موفق، exit 0؛ بدون هشدار |
| `pnpm run test` | ۳۳ تست موفق |
| `pnpm run test:production` | موفق؛ مسیر فارسی عمومی، redirect نقش‌های مدیر و وضعیت‌های ۲۰۰/۴۰۴ پنل با سرویس HTTP نمونه |
| `pnpm exec playwright test --config playwright.reference.config.ts` | هر چهار تست موفق؛ هشت تصویر از دو صفحه در چهار عرض |
| بازبینی دستی تصاویر | خانه و پروفایل دسکتاپ و نمایش موبایل بررسی شدند؛ تصویر شهر، ستون معرفی، فوتر و کارت‌ها با مرجع تطبیق داده شدند |
| `git diff --check` و `git diff --cached --check` | موفق؛ تغییرات staged قبلی دست‌نخورده باقی ماندند |

در آزمون نهایی، تصاویر شکسته، سرریز افقی و خطای JavaScript مرورگر دیده نشدند. فایل‌های runtime بررسی‌شده در کپی ایزوله با فایل‌های اصلی یکسان‌اند. آزمون ناموفق اولیه از خروجی قدیمی build استفاده می‌کرد؛ پس از ساخت سورس نهایی، تمام چهار حالت دوباره اجرا و موفق شدند. خطای اولیه فهرست سورس و هشدار import استفاده‌نشده نیز برطرف شدند.

آزمون اختصاصی مرورگر: `pnpm exec playwright test --config playwright.reference.config.ts`، پس از `pnpm run build`. این تنظیمات سرور فرانت را روی پورت ۳۰۰۲ و سرویس HTTP نمونه را روی پورت ۳۱۰۲ اجرا می‌کنند؛ هیچ دیتابیس یا سرویس اصلی استفاده نمی‌شود. این آزمون، تأیید اتصال به بک‌اند واقعی نیست.

عرض‌های تست: ۳۷۵، ۷۶۸، ۱۰۲۴ و ۱۴۴۰. کنترل‌ها شامل سرریز افقی، فونت، تصاویر شکسته، خطاهای مرورگر، جای ستون‌ها، فیلتر و حالت خالی محصولات، قیمت تخفیف‌دار، جابه‌جایی گالری و بسته‌شدن پنجره تماس با بازگشت فوکوس هستند.

بررسی‌های دیتابیس، migration و پنج کنترل قرارداد API برای تغییرات این تسک کاربرد ندارند، چون schema، قرارداد و کلاینت تولیدشده در این تسک تغییر نکرده‌اند. canonical، احراز هویت و عملیات ثبت نظر موجود حفظ شدند. هیچ commit یا push انجام نشده و تغییرات قبلی کاربر stage یا بازنویسی نشده‌اند.

## محدودیت‌ها

- نظرات صفحه خانه از محتوای نمونه موجود در سورس طراحی‌اند؛ سرویس نظرات عمومی تازه‌ای اضافه نشده است.
- تصاویر، محصولات، نظرات، شبکه‌های اجتماعی و نقشه پروفایل بر اساس داده‌های واقعی هر کسب‌وکار نمایش داده می‌شوند. آزمون نمونه مختصات نقشه ندارد و سرویس نقشه خارجی را تأیید نمی‌کند.
- تطبیق تصویری دستی انجام می‌شود؛ ادعای مقایسه خودکار پیکسل‌به‌پیکسل با پیوست‌ها وجود ندارد.
