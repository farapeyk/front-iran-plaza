# ظاهر صفحه فهرست کسب‌وکارها — ۲۰۲۶-۱۰-۱۲

مرجع این تسک تصویر `3.png` پیوست کاربر است. صفحه `/businesses/` با کارت‌های دو ستونه در دسکتاپ و تک‌ستونه در موبایل، جستجو در سمت چپ، فیلترهای بالای فهرست، نوار ثبت‌نام پس از شش کارت، عضوهای جدید و متن معرفی پایین صفحه تنظیم شد. فوتر همان سبک صفحات مرجع قبلی را دارد.

«مشاهده بیشتر» صفحه بعد سرویس فعلی را دریافت می‌کند و نتایج را بدون تکرار شناسه به فهرست اضافه می‌کند. تغییر فیلترها صفحه را به اول برمی‌گرداند. ورود با Enter یک بار جستجو را اجرا می‌کند و متن جستجو هنگام برگشت مرورگر با URL هماهنگ می‌شود. نشان VIP و اقساط به داده واقعی وابسته‌اند.

## نتایج نهایی

| بررسی | نتیجه |
| --- | --- |
| `pnpm run build` | موفق، exit 0؛ سورس نهایی در کپی ایزوله بدون env خصوصی |
| `pnpm run typecheck` | موفق، exit 0 |
| `pnpm run lint` | موفق، exit 0 و بدون هشدار |
| `pnpm run test` | ۳۳ تست موفق روی تغییرات نهایی |
| `pnpm run test:production` | موفق؛ مسیر فارسی عمومی، redirect مدیران و وضعیت‌های ۲۰۰/۴۰۴ پنل با HTTP fixture |
| `pnpm exec playwright test --config playwright.reference.config.ts` | هر ۸ تست موفق روی نسخه تولید؛ سه صفحه در چهار عرض |
| بررسی دستی تصاویر | فهرست در عرض ۱۴۴۰ و ۳۷۵ با مرجع مقایسه شد؛ چیدمان، کارت‌ها، نوار ثبت‌نام و بخش‌های پایین بررسی شدند |
| `git diff --check` و `git diff --cached --check` | موفق؛ تغییرات staged قبلی حفظ شدند |

عرض‌ها: ۳۷۵، ۷۶۸، ۱۰۲۴ و ۱۴۴۰. چهار تست جدید فهرست، تعداد ستون‌ها، جای نوار ثبت‌نام، افزودن نتایج ۲۰ به ۲۴، نبود دکمه بیشتر در انتهای نتایج، فیلتر VIP، ارسال فیلتر رسانه به سرویس، انتخاب شهر، حالت بدون نتیجه، Enter و برگشت مرورگر را بررسی کردند. چهار تست قبلی خانه و پروفایل نیز دوباره موفق شدند. در آزمون‌ها تصویر شکسته، سرریز افقی یا خطای JavaScript دیده نشد.

## دامنه و محدودیت

- سرویس مرورگر و تست نسخه تولید، fixture HTTP محلی است؛ نتیجه، تأیید دیتابیس یا بک‌اند واقعی نیست.
- تلاش اولیه برای تست dev به زمان کامپایل اولیه صفحه و مسیر BFF خورد و موفق نبود. تست‌های نهایی روی نسخه کامپایل‌شده تولید اجرا و همگی موفق شدند؛ نتیجه dev به‌عنوان قبولی استفاده نشده است.
- قرارداد API، کلاینت تولیدشده، بک‌اند و schema در این تسک تغییر نکرده‌اند. کنترل‌های migration و پنج کنترل تغییر قرارداد API برای این تسک کاربرد ندارند.
- نمایش متن و لینک‌ها با JSX و مسیرهای موجود بررسی شد؛ هیچ HTML خام یا مقصد URL آزاد به کارت‌ها اضافه نشده است. عنوان صفحه و ناوبری پروفایل‌ها حفظ شدند.
- هیچ commit یا push انجام نشد. خروجی تصاویر و manifest سورس در `artifacts/listing-reference/` مخزن coordination نگهداری می‌شوند و وارد Git محصول نمی‌شوند.
