# گزارش بررسی اولیه فرانت‌اند

این سند سابقه **قبل از اصلاحات** است. وضعیت جاری، اصلاح هر یافته و QA جدید در [گزارش تغییرات](CHANGES-2026-10-07.md) آمده است. جدول‌ها و نتایج زیر وضعیت امروز کد اصلاح‌شده نیستند.

تاریخ بررسی: ۲۰۲۶-۱۰-۰۷. دامنه: کد، تنظیمات، صفحات، actionها، مدل‌ها و تست‌های موجود در `front-iran-plaza`. در این کار مستندات اضافه شده‌اند و کد اجرایی تغییر نکرده است.

## یافته‌های قابل پیگیری

اولویت‌ها پیشنهاد حاصل از بررسی سورس هستند. موارد وابسته به زیرساخت بدون تست واقعی به عنوان نقص قطعی بک‌اند گزارش نمی‌شوند.

| اولویت | مشاهده و شاهد | اثر / اقدام پیشنهادی |
| --- | --- | --- |
| بالا | refresh cookie فقط `/api/auth` است، ولی handler `/api/backend` برای retry آن را می‌خواند؛ `constants/auth.ts` و handler backend | refresh خودکار عمومی قابل اتکا نیست؛ الگوی handshake مورد استفاده onboarding را برای مسیرهای لازم ارزیابی و با مرورگر تست کنید. |
| بالا | برخی Server Actionها مانند submit-document و update-business-profile صرفاً type ورودی دارند؛ auth actionها از Zod استفاده می‌کنند | ورودی‌های action قابل جعل‌اند؛ اعتبارسنجی runtime و مجوز/مالکیت backend باید تأیید شود. |
| بالا | `src/error.tsx` بیرون `src/app` قرار دارد | این فایل در جایگاه error boundary ریشه App Router نیست؛ مدیریت خطای صفحه‌ها را بررسی کنید. |
| بالا | GET silent-refresh و proxy backend پاسخ توکن را با cast می‌پذیرند، درحالی‌که POST silent-refresh بررسی بیشتری دارد | اعتبارسنجی پاسخ auth بین مسیرها یکسان نیست؛ ساختار توکن و رفتار پاسخ نامعتبر را پوشش دهید. |
| متوسط | لینک‌های فاقد صفحه در خانه، داشبورد و sidebar؛ فهرست در ROUTES | مسیر کاربر قطع می‌شود؛ لینک را به صفحه موجود وصل یا صفحه مقصد را پیاده کنید. |
| متوسط | dashboard حضور نوع مدرک را کافی می‌داند، layout پروفایل REJECTED را ناکافی می‌داند | وضعیت ثبت و مقصد ادامه ممکن است متفاوت شود؛ انتظار محصول و منطق مشترک را مشخص کنید. |

| متوسط | `upload-file.action.ts` نام multipart و `document-review-card.tsx` مسیر فایل را در comment فرضی می‌دانند | دریافت و ارسال فایل باید با قرارداد رسمی و درخواست واقعی تأیید شود. |

| متوسط | slug ناموجود متن «پیدا نشد» برمی‌گرداند و `notFound()` فراخوانی نمی‌شود | status مناسب نبود صفحه و SEO نیازمند بررسی واقعی response است. |
| متوسط | metadata عمومی ریشه وجود دارد، generateMetadata اختصاصی، sitemap و robots در سورس دیده نشد | برای صفحات کسب‌وکار و جلوگیری از index صفحات خصوصی برنامه SEO تکمیل شود. |
| متوسط | admin listها و countها از پاسخ‌های محدود ۵۰/۱۰۰ استفاده می‌کنند | pagination، total و کامل‌بودن آمار با قرارداد پاسخ کنترل شود. |
| متوسط | ثبت دستی کسب‌وکار و تغییر پلن دو درخواست جدا هستند | شکست مرحله دوم ممکن است کسب‌وکار ایجادشده باقی بگذارد؛ retry و نمایش نتیجه جزئی را بررسی کنید. |
| متوسط | upload محدودیت یکسانی در همه فرم‌ها ندارد؛ accept مرورگر و سقف ۲۰MB فقط برخی جاهاست | محدودیت اندازه، MIME واقعی، مالکیت و مجوز فایل در server/backend بررسی شود. |
| پایین | دو lockfile، نبود engines/packageManager، تنظیمات build dependency در pnpm-workspace | نصب و CI را با نسخه ابزار و lockfile مرجع قابل تکرار کنید. |
| پایین | `BusinessFeature` دو تعریف با requiredness متفاوت دارد؛ nav-config نقش‌هایی متفاوت از CurrentUser معرفی می‌کند | typeها و نقش‌های واقعاً مصرف‌شده را یکدست کنید. |
| پایین | پروژه RTL است ولی `components.json` مقدار `rtl: false` دارد | هنگام تولید اجزای جدید، جهت و دسترس‌پذیری را بررسی کنید. |
| پایین | Geist با subset لاتین و دریافت از Google در root layout تعریف شده | فونت فارسی و دسترسی build به فونت را در محیط مقصد تأیید کنید. |

`jose.jwtVerify` در verifier بدون محدودیت صریح `algorithms` یا issuer/audience تنظیم شده و payload با generic تایپ شده است. نیاز به محدودیت این claimها و الگوریتم باید با قرارداد احراز هویت واقعی تعیین شود؛ این بررسی نفوذ یا اثبات آسیب‌پذیری نیست. پراکسی همچنین headerهای درخواست/پاسخ را عمدتاً منتقل می‌کند؛ برای policy header، cache، Set-Cookie و پاسخ فایل بررسی عملی لازم است.

## نکات مثبت قابل مشاهده

- secretها با نام server-only مصرف می‌شوند و tokenها در کوکی HttpOnly هستند.
- مسیر redirect در silent-refresh به مقصد داخلی محدود شده است.
- handshake JSON برای پیشرفت مرحله مانع هدایت mutation به navigation می‌شود.
- در onboarding، پاسخ مرحله از نظر integer و بازه بررسی و کلیک همزمان محدود می‌شود.
- اعتبارسنجی OTP، کد ملی و فرم‌های اولیه با schema انجام می‌شود.
- ترتیب ۱۱ مرحله و ارسال دسته انتخابی تست محلی دارند.

## نتایج QA همین بررسی

| فرمان / بررسی | نتیجه تازه | حدود اعتبار |
| --- | --- | --- |
| `node --test tests/onboarding.test.cjs` | موفق؛ ۳ از ۳ تست | تست محلی؛ fetch و cookie در تست ثبت mock هستند. |
| `npx --no-install tsc --noEmit --incremental false` | موفق؛ exit code صفر | بررسی ایستای TypeScript، بدون اثبات قرارداد HTTP |
| `npm run lint` | ناموفق؛ ۱۳ error و ۱۱ warning | مشکلات سورس موجود؛ در این کار کد اصلاح نشده است. |
| کنترل مستندات با اسکریپت inline و `node -` | موفق؛ ۱۰ سند، ۲۱ لینک محلی، فهرست ۱۷۶ فایل و پوشش ۳۴ صفحه | کنترل UTF-8، fenceها، whitespace، وجود مقصد لینک و تطابق فهرست با سورس |
| `npm run build` | اجرا نشده | تغییر فقط مستندات است و runtime/dependency تغییر نکرده است. |
| API، مرورگر و دیتابیس واقعی | اجرا نشده | این بررسی محیط و حساب آزمون واقعی را ارزیابی نکرده است. |

خطاهای lint: یک `react-hooks/set-state-in-effect` در `onboarding-context.tsx:32`، پنج `prefer-const` در `jalali.ts` و هفت خطای تنظیمات CommonJS در `tests/onboarding.test.cjs` شامل `no-require-imports` و `no-assign-module-variable`. warningها عمدتاً import/متغیر استفاده‌نشده، `watch` در React Hook Form و استفاده از img هستند. این یافته‌ها gate commit کد را موفق نمی‌کنند و باید در کار اصلاحی مستقل یا دامنه مجاز بعدی رفع شوند.

گزارش `ONBOARDING-UPDATE.md` به عنوان شاهد QA فعلی استفاده نشده است. کنترل مستندات ابتدا با Python تلاش شد، اما Python در PATH قابل اجرا نبود؛ همان کنترل‌ها با Node اجرا و موفق شدند. فایل چک‌لیست موجود و README ریشه دست‌نخورده باقی مانده‌اند؛ ۱۰ سند جدید در `docs/` اضافه شده‌اند.

## محدودیت‌ها

پوشه فعلی Git repository نیست؛ `git status --short` و `git ls-files` خطای `not a git repository` دادند. staged diff و `git diff --cached --check` قابل ارزیابی نیستند و commit انجام نشده است. بررسی API با HTTP واقعی، SMS، حساب واقعی، storage، دیتابیس، migration، مرورگر و E2E انجام نشده است. build production برای تغییر صرفاً مستندات اجرا نمی‌شود؛ کد runtime یا dependency تغییر نکرده است.
