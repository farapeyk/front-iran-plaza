# رابط پلن‌های VIP

## مدیریت

مسیر `/admin/plans` فقط برای `SUPER_ADMIN` است. مدیر ارشد در این صفحه نام، قیمت ثبت‌شده، مدت (پیش‌فرض ۳۰ روز)، سقف عکس/محصول/خدمت/تخفیف، اولویت و گزینه‌های نقشه، ویدیو، شعب، ساعات، اقساط، شبکه اجتماعی، ویژگی سفارشی و آمار را تعیین می‌کند. پلن را می‌توان ویرایش یا برای اعطاهای بعدی غیرفعال کرد. لینک این صفحه فقط برای مدیر ارشد در sidebar دیده می‌شود و Server Action نیز نقش را دوباره کنترل می‌کند.

مدیر از صفحه جزئیات هر کسب‌وکار پلن VIP فعال را اعطا می‌کند یا کسب‌وکار را به FREE برمی‌گرداند. تاریخ پایان اعتبار در همان کنترل نمایش داده می‌شود. صفحه اشتراک صاحب کسب‌وکار فقط پلن‌ها و توضیح هماهنگی با ادمین را نشان می‌دهد؛ دکمه خرید یا trial ندارد، چون پرداخت آنلاین فعلاً فعال نیست.

## نمایش عمومی

کارت خانه و فهرست از `planType` و `planExpiryDate` واقعی استفاده می‌کنند و فقط اشتراک آینده را VIP می‌دانند. نشان تصویری `/design/shared/vip-badge.webp` در کارت‌ها، کسب‌وکارهای داخل مقاله و سربرگ/کارت کناری صفحه کسب‌وکار نمایش داده می‌شود. فیلترهای «فقط VIPها» و «دارای تصویر/ویدیو» به query واقعی `vipOnly` و `hasMedia` متصل‌اند. ترتیب API ابتدا VIP معتبر و سپس سایر کسب‌وکارهاست.

## قرارداد و QA

کلاینت Orval از OpenAPI بک‌اند بازتولید شده و فیلدهای VIP فهرست و پروفایل را به‌صورت type-safe مصرف می‌کند. تست‌های عمومی موجود فهرست و مقاله باید همراه با `pnpm test` اجرا شوند؛ `pnpm typecheck`، `pnpm lint` و `pnpm build` نیز بررسی نهایی runtime هستند.
